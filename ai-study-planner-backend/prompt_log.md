# Prompt Log

This project was developed with Codex. Update this log as you continue working.

## Tools and models used

- Codex: project planning, Flask implementation, validation, frontend implementation, documentation, and debugging.
- OpenAI API model: configured through `OPENAI_MODEL`; the initial default is `gpt-4o-mini`.

## Important development prompts

- "What is this assignment asking me to do?"
- "Give me some ideas on what to make."
- "How to integrate APIs into this?"
- "Could I use the OpenAI API for something?"
- "Build this website for me and tell me what I need to do to help."

## Runtime prompt approach

The backend instructs the model to act as a practical academic planning assistant, fit all sessions and breaks within the user's time limit, prioritize closer deadlines and lower confidence, avoid inventing course requirements, and return a typed study-plan structure.

Do not include API keys, passwords, or other secrets in this log.
